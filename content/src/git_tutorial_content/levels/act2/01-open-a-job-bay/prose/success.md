`git status` says you are on `aisle-d-fitout`, and every file is
exactly as it was a minute ago.

That is worth sitting with, because most people expect it to be
untrue. Making a branch copied nothing. Both names point at the same
commit right now; the only difference is which one moves when you
make your next commit.

  git branch

The `*` marks where you are. From here, work you commit lands on
`aisle-d-fitout`, and `main` stays where the team left it. Next job:
step off the bay and see what happens to your files.
