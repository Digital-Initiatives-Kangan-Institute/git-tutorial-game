Make a branch called `aisle-d-fitout` and be standing on it. Leave
`main` where it is, and do not edit anything yet.

  git branch              list the branches that exist
  git switch -c <name>    make a branch here and move onto it

A branch is a name pointing at a commit. Making one changes no files:
afterwards your working tree looks exactly as it does now, and
`git status` says "On branch aisle-d-fitout" instead of "On branch main".
