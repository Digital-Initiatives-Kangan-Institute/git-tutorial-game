Get `docs/safety.md` into the history as one new commit. The file is
already written. You do not need to edit anything.

  git status                  untracked, staged, or neither
  git add <path>              stage it
  git commit -m "<message>"   record what is staged

`git add` puts a change in the staging area (also called the index).
`git commit` records what is staged and nothing else.

The text after -m is the commit message, written for whoever reads
the history later.
